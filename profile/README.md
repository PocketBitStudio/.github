## 🚀 About PocketBit

PocketBit is an independent game development studio
dedicated to creating immersive gaming experiences
for Web and Mobile platforms.

Inspired by classic arcade games, retro-futuristic
aesthetics, and modern technologies, we combine
nostalgia with innovative game design.

Our mission is to reimagine classic gaming experiences
while building exciting new digital worlds.
